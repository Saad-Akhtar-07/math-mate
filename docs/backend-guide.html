How the numbers work
  • Each marked check adds evidence to every skill in that question.
  • Work done alone counts fully. Work done after hints counts half, and after a full solution a quarter.
  • Old evidence slowly fades, losing half its weight every 30 days.
  • With only a few attempts, a skill stays near the student's average for that topic and is marked as unsure.
  • The tutor gets a 4-line summary like the card on the left. It uses it to choose where help starts and how to word it.
